# Roles and access **[verified: code]**

| Role | System | Can do | Can't do |
|---|---|---|---|
| Salamah (admin) | CRM | Sales, pipeline, purchases, assets, approvals, engineers, settings | — |
| Survey engineer | CRM | Survey job only | Other jobs |
| Delivery engineer | CRM | Delivery scans | — |
| Installation engineer | CRM | Install stages, asset scans, crew | — |
| Maintenance engineer | CRM | Daily checks, fix jobs | — |
| OmniSite team | Dashboard | Factories, people, pilot equipment, Connections, Support | See batches, kg, money |
| Site manager (several per factory) | Dashboard | Batches, QC, stop reasons, losses, settings | Add equipment, switch machines on / off |
| Owner (view only; can have several factories) | Dashboard | See everything of his factories | Edit |

Logins: email + password (≥ 10 characters), 30-day sessions, lockout after 5 wrong tries.
