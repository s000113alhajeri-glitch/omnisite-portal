# Customer journey

Consultation → operational audit (8 points) → baseline report → NDA → scope of work → pilot proposal → agreement → site survey → engineering files → readiness (scope meeting, down payment, crew) → delivery → installation → live → 2-week recording vs baseline → result (customer, or lost with reason + follow-up date) → subscription, maintenance and support.

Each step has a protocol in [04_protocols](../04_protocols/).
