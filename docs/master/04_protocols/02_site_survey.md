# Protocol 2: Site survey (engineer)

Source: CRM survey job. **[verified]**

1. **Before the visit:** print blank QR machine labels (M-001…) and power labels (P-…); charge phone, laser meter, label printer.
2. **Section 1–2:** flow vs P&ID; production lines → ordered steps, each with a description + photo; 1 Google Drive video per line.
3. **Section 3, Floor plan:** add each hall: name, length + width in cm, compass heading along the wall from corner A1, photo of corner A1.
4. **Section 3, Equipment:** for each item: Type (Machine / Tool / Fixed / Power / Marker) → Scan label → Take photo · AI reads it → check the AI fields → + Add equipment. Then on its card: hall, laser-meter cm from A1 (along, out, height), size (length, width, height), shape.
5. **Phone technique:** upright, chest height, slow, overlapping side-to-side sweeps, get close for labels and nameplates, finish where you started.
6. **Sections 4–5:** the 8 audit points, photos (at least 1).
7. **Send for review** (sections 1–5). Salamah approves or sends back with a note.
8. **Section 6, within 3 working days (Sat/Sun skipped):** upload the 6 engineering files: E-01 Power single-line diagram, E-02 System architecture (data), E-03 Enclosure wiring layout, E-04 Load schedule, Installation & site execution plan, Equipment schematic. Salamah approves each file.
9. The survey can't be sent until each item has hall + position + size and the required photos.
