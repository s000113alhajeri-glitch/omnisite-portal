# OmniSite Master File

Single place for everything about OmniSite: knowledge, legal, operations, protocols, artifacts and code.

**Source rule:** each fact is marked **[verified]** (checked in code, an official site or a document), **[decision]** (Salamah decided it), or **[assumption]** (not confirmed yet). Nothing in here should be invented. Update this file when something changes.

**Confidential.** Internal only. Do not share the Chemex P&ID, plant layout or pilot scope outside OmniSite.
