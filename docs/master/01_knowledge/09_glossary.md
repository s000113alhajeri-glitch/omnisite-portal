# 9. Glossary

| Term | Meaning |
|---|---|
| Batch | One mix in the mixing tank, ID MX1-YYYYMMDD-## |
| Re-mix | A batch that failed QC and was mixed again (with a top-up) |
| QC | Quality check: pH and viscosity |
| Baseline | 2 weeks of recording before changes, used to measure the gain |
| A1 | The fixed corner every position is measured from (cm) |
| Machine label | QR code M-001 (machine), T- (tool), F- (fixed), P- (power), A- (marker) |
| Marker / anchor | A measured QR (A-001) that resets the phone's position |
| Drift | Position error that grows while the phone guesses its movement |
| Gateway | The 4G box (Teltonika TRB246) that sends readings to OmniSite |
| Modbus | The language the drive and sensor modules use on RS-485 wires |
| Digital twin | 3D copy of the hall and machines with live status |
| Source | Where a value came from: Manual, Estimate or Sensor |
| P&ID | Piping and instrumentation diagram |
| PDPL | UAE Personal Data Protection Law |
| RAG | AI answering from your own documents (not used yet) |
